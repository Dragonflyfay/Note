## SQL分类
### ⭐DDL：定义 
CREATE ALTER  DROP RENAME truncate
- 查询<br>
    查询所有<br>
    ```sql
    SHOW DATABASES;
    ```
    查询当前
    ```sql
    SELCT DATABASE();
    ```
    
- 创建<br>
 ```sql
 CREATE DATABASE[IF NOT EXISTS] 数据库名[DEFAULT CHARSET 字符集][COLLATE 排序规则]
 ```
- 删除
- 使用

### ⭐DML：操作(增删改查)
INSERT DELETE UPDATE SELECT(DQL)
### DCL：控制
COMMIT ROLLBACK (TCL) SAVEPOINT GRANT REVOKE<br><br>
⚠️**SQL在Windows下不区分大小写，在Linux下区分大小写**
### 注释：
```
单行注释：#注释文字(MySQL特有)
单行注释：--注释文字(--后必须包含一个空格)
多行注释： /* 注释文字*/
```
